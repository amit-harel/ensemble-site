# ensemble-site

The public home page and privacy policy of Ensemble, a personal agent hub (repo `agent-fleet`).
Served by GitHub Pages at https://amit-harel.github.io/ensemble-site/ — the Google OAuth consent
screen links to `index.html` (home page) and `privacy.html` (privacy policy).

Plain static HTML, no build. Preview locally with `python3 -m http.server 8478`.
